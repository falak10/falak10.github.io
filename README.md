# Falak Alghamdi: data analysis portfolio

Personal portfolio with Power BI, Python and R case studies.

Live site: https://falak10.github.io

## Structure

A static site with no build step.

- `index.html`: the whole page, including its styles and scripts
- `404.html`: page shown for broken links
- `assets/og.png`: image shown when the link is shared
- `robots.txt`, `sitemap.xml`: for search engines
- `.nojekyll`: tells GitHub Pages to serve the files as they are

## Run locally

```bash
python3 -m http.server 8123
```

Then open http://localhost:8123.
